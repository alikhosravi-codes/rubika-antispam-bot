# 08 — راهنمای کلی دستورات ربات

نام دقیق بعضی دکمه‌ها و دستورات بسته به نسخه و تنظیمات پنل ممکن است متفاوت باشد، اما ساختار کلی این است.

## نصب ربات در گروه

بعد از اضافه کردن ربات به گروه، مالک/ادمین گروه دستور نصب یا پنل را اجرا می‌کند. در نسخه‌های جدید، گروه‌ها پیش‌فرض غیرفعال هستند و باید از پنل فعال شوند.

## پنل مدیریت

از داخل گروه یا چت مالک، پنل را باز کن و بخش‌های زیر را مدیریت کن:

```text
قفل‌ها
اخطارها
جریمه قفل‌ها
ادمین‌های داخلی
کاربران معتمد
کلمات بد
پیام همگانی
آمار
تنظیمات گروه
خروجی/ورود تنظیمات
```

## قفل‌ها

هر قفل می‌تواند روشن/خاموش شود، مثل:

```text
لینک
آیدی روبیکا
عکس
فیلم
فایل
فوروارد
کپشن
ایموجی
شماره
ایمیل
فحش/کلمات بد
فlood/اسپم
تکرار پیام
```

برای هر قفل می‌توان سطح اخطار و نوع جریمه تعیین کرد.

## جریمه‌ها

جریمه‌های قابل استفاده:

```text
بن
سکوت
سیک/اخراج
فقط حذف
بدون جریمه
```

## ادمین‌های داخلی

ادمین داخلی ربات با ادمین خود روبیکا فرق دارد. این لیست داخل دیتابیس ربات نگهداری می‌شود و برای دسترسی به پنل ربات استفاده می‌شود.

در نسخه‌های جدید `group_admins` به شکل لیست ساده آی‌دی ذخیره/خوانده می‌شود تا مشکل دسترسی پیش نیاید.

## کاربران معتمد

کاربران معتمد از بعضی محدودیت‌ها مستثنا می‌شوند. این بخش برای کاربران VIP یا مدیران غیررسمی گروه کاربرد دارد.

## خروجی و ورود تنظیمات گروه

برای انتقال تنظیمات یک گروه یا بکاپ گرفتن از قفل‌ها، از گزینه‌های خروجی/ورود تنظیمات استفاده کن.

## پیام همگانی

پیام همگانی مستقیم ارسال نمی‌شود؛ داخل صف می‌رود و با `cron_broadcast.php` ارسال می‌شود. پس برای پیام همگانی باید کرون فعال باشد.
