پچ v86 — فعال‌سازی ربات برای مدیران مستقل هر گروه
====================================================

تغییرات:
1) محدودیت نصب اولیه فقط توسط مالک اصلی برداشته شد.
2) شخصی که ربات را به گروه اضافه می‌کند، از شناسه خود ربات تفکیک و مدیر داخلی همان گروه ثبت می‌شود.
3) گروه بلافاصله بعد از اضافه‌شدن ربات فعال می‌شود.
4) بعد از اینکه ربات در تنظیمات گروه مدیر شد و مجوز حذف پیام گرفت، قفل‌ها کار می‌کنند.
5) اگر روبیکا شناسه اضافه‌کننده را در رویداد نفرستد، یکی از مدیران گروه فقط یک‌بار داخل گروه دستور «نصب» را می‌زند.
6) مشکل اشتباه تشخیص‌دادن رویداد ورود به‌عنوان خروج نیز اصلاح شد.
7) جوین اجباری، پنل اصلی مالک، پیام همگانی و سایر دسترسی‌های سراسری تغییر نکرده‌اند.

روش نصب پچ:
- از فایل‌های فعلی بکاپ بگیر.
- پوشه src داخل این پچ را روی پوشه src هاست جایگزین کن.
- فایل config.sample.php فقط نمونه جدید است؛ config.php فعلی خودت را حذف یا جایگزین نکن.
- فایل tests/group_join_patch_test.php اختیاری است و برای تست CLI قرار داده شده.

نکته config.php:
برای نصب معمولی هیچ تغییری لازم نیست. کد v86 اگر گزینه زیر در config.php وجود نداشته باشد، آن را فعال در نظر می‌گیرد:

'install_security' => [
    'allow_group_manager_install' => true,
    'owner_only_first_install' => true,
    'allowed_installer_ids' => [],
],

برای بازگرداندن رفتار قبلی و محدودکردن اولین نصب به مالک اصلی، مقدار allow_group_manager_install را false کن.

تست اختیاری:
php tests/group_join_patch_test.php

- src/BotAppHelpers.php
